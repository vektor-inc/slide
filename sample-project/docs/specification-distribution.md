# 提供形態（Pro版 / 無料版 GitHub Release / 無料版 .org）仕様

## 概要
本プロジェクトは以下 3 種類の提供形態を持つ。各形態の位置づけと配布経路、ドキュメントの参照先を明確化し、実装・運用・サポート時の混乱を防ぐ。

## 提供形態一覧
1. **Pro版**
   - 商用提供の本体版。機能は最もフルセット。
   - 仕様書は `docs/` 配下の各仕様に従う。
2. **無料版 GitHub Release 版**
   - GitHub Releases から配布する無料版。
   - 機能制限がある前提で、無料版の配布チャネルとして運用する。
   - GitHub Release からアップデートするプログラム（`class-vkbm-github-updater.php`）が含まれる。
3. **無料版 .org 版**
   - WordPress.org に配布する無料版。
   - GitHub Release 版と同じ無料版カテゴリとして扱うが、WordPress.org の審査・公開ルールに準拠する。
   - 翻訳ファイル及び翻訳読み込みに関する記述を削除する。
   - GitHub Release からのアップデートに関するプログラム（`class-vkbm-github-updater.php`）は含まない。

## ドキュメントの参照先
- Pro 版の機能仕様は `docs/` 配下の仕様書を正とする。
- 無料版の公開向け情報は以下を参照する。
  - GitHub Release 版: `README-FREE.md`
  - WordPress.org 版: `readme.txt`

## 機能差分の管理方針
- Pro 版と無料版で機能差分がある場合は、次のいずれかに必ず明記する。
  - 仕様書（機能仕様）側に「Pro版のみ / 無料版には含まれない」旨を記載
  - 公開向けドキュメント（`README-FREE.md` / `readme.txt`）に明記
- 差分が広範囲に渡る場合は、該当する仕様書に「無料版制限」セクションを設けて整理する。

## バージョン表記の方針
- Pro 版と無料版は同一コードベースであっても、配布チャネルごとにリリース管理を行う。
- 表示上は「Pro版」「無料版（GitHub Release）」「無料版（.org）」の名称を明示する。
